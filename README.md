# aidiff

**aidiff** is based on [revdiff](https://github.com/umputun/revdiff), with an integrated terminal and [T3 Code](https://github.com/pingdotgg/t3code) support.

Run `aidiff` from any folder. In a repository it shows changes; outside a repository it browses the folder's files, with live refresh and the integrated terminal available. Use `--only path/to/file` to open specific files, or `--include` / `--exclude` to filter the file tree.

Outside repositories, folders load lazily: only the top level is read initially. Select a directory and press Enter or click it to expand/collapse it; Right opens it and Left closes it. Live refresh watches only the root and expanded directories. The file picker searches files in expanded directories.

Every folder opened from the history panel and every T3 project is a session that keeps running in the background. Ctrl+Tab opens a switcher that lists them most recently used first, with the previous session selected, so one press goes back to it. Each further press moves down (Ctrl+Shift+Tab moves up) and shows the selected session at once. The list stays open as long as Ctrl is held, and letting go of Ctrl switches there, in a terminal that reports key releases through the kitty keyboard protocol (kitty, Ghostty, foot, WezTerm with `enable_kitty_keyboard`, Alacritty, iTerm2). Elsewhere (tmux, GNOME Terminal, Konsole, Terminal.app, VS Code's and T3 Code's terminals) it stays open until Enter; a digit, a click or any other key switches too, in every terminal, and Esc goes back. Ctrl+Tab reaches aidiff only in a terminal that reports modified keys and does not keep the chord for its own tabs, so Alt+S does the same in every terminal (letting go of Alt switches where releases are reported), and ctrl+p → Switch session… opens it too. To free Ctrl+Tab: Ghostty `keybind = ctrl+tab=unbind`, kitty `map ctrl+tab no_op`, WezTerm `DisableDefaultAssignment`, Windows Terminal `"command": "unbound"`, tmux `set -s extended-keys on` (and the same for Ctrl+Shift+Tab).

T3 chat shows sent messages above the input while they are sending or queued, then moves them into the conversation when T3 starts processing them. A persistent status line shows whether the agent is working, waiting for you, or idle, with active subagent and process counts. Press Left with an empty input to inspect activity. Counts use live server events without polling.
